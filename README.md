## How I document projects
Each practical project should include:
1. **Scenario and objective** — what suspicious behavior is being investigated.
2. **Lab setup and data provenance** — tools, versions, dataset source, and safe lab boundaries.
3. **Implementation** — setup commands, configuration, query/rule, and how to reproduce it.
4. **Evidence and results** — screenshots or sanitized sample output, relevant fields, and a short timeline.
5. **Analyst conclusion** — true positive/benign/needs-more-data, confidence, impact, and limitations.
6. **Response recommendations** — immediate containment, follow-up checks, and prevention.
7. **Validation** — test cases, expected results, and known false positives.
